# Figures

All figures are generated by `python scripts/generate_figures.py` from the
checked-in files under `results/`. The charts use the final scorer output and
pooled two-repeat performance tables. Bars start at zero. The script requires
Python and Pillow.

- `overall-capability.png`: overall capability score, GPT-5.6 Luna 0.9064 and
  GPT-6 Luna 0.8616.
- `category-comparison.png`: category capability scores for AGENT, CODE, CTX,
  EVID, EXTR, REAS, and WRITE.
- `pairwise-results.png`: 59 judged pairs, GPT-5.6 Luna wins 23, GPT-6 Luna
  wins 14, and 22 ties.
- `latency-comparison.png`: pooled mean, median, and P90 latency in seconds.
  The CLI versions differed, so this is an end-to-end transport observation.
- `repeat-consistency.png`: exact agreement and mean absolute difference across
  the two repeats per model.
